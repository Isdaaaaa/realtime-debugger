# Demo Capture Setup

## Scene prep
- Theme: dark mode only
- Browser zoom: 100%
- Viewport: 1440x900 or 1920x1080
- Hide bookmarks/extensions for cleaner framing

## Capture settings
- 30 fps minimum (60 fps preferred)
- H.264 MP4 output
- Bitrate target: 8–12 Mbps (1080p)
- Cursor highlight enabled

## Recording script
1. Load `Retry Storm` scenario
2. Press `Space` to play for ~3s
3. Press `Space` to pause
4. Step with `→` over retry/drop/duplicate events
5. Select an anomaly event and show inspector callout
6. Use event filter chips to isolate `retry` and `duplicate`
7. Return to `all` focus and jump to a later event

## Portfolio packaging
- Export GIF teaser (8–12s) and MP4 full clip (15–20s)
- Save hero screenshot of split timeline/inspector view
- Include one caption per clip focused on debugging insight, not visuals
