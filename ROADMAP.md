# Roadmap

## Phase 1 — Foundations
- Project scaffolding (Vite, TypeScript, Tailwind)
- Design tokens and layout skeleton
- Mock transport service and sample event fixtures

## Phase 2 — Timeline & Playback
- Timeline visualization with grouped connection/message events
- Step/auto-play controls, speed adjustments, and seek by event
- Event payload viewer with diffing for duplicates/missed messages

## Phase 3 — State Inspector
- Client state machine with XState
- State snapshot panel with time-aligned updates
- Highlight discrepancies (out-of-order, dropped, duplicates)

## Phase 4 — Scenario Presets
- Chat presence and live notifications presets
- Reconnect storm and backpressure scenarios
- Inline explanations for each preset’s expected vs. observed behavior

## Phase 5 — Polish & Demo
- Empty/error states, keyboard shortcuts, accessibility pass
- README polish, demo script, and GIF capture workflow
- Publish portfolio-ready screenshots and narrative
